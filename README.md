# Cupom Maníacos 🛒🤖

> **Curso:** Análise e Desenvolvimento de Sistemas (ADS)

## 📌 Sobre o Projeto

O **Cupom Maníacos** é um assistente conversacional (bot) integrado ao Telegram, desenvolvido para transformar a jornada de compras online. Em vez do modelo tradicional de notificações passivas (onde o usuário recebe centenas de alertas irrelevantes por dia), o sistema introduz a **busca ativa por intenção de compra**.

O usuário define o produto desejado e um "preço-alvo". O sistema, então, realiza o monitoramento silencioso do mercado, considerando o custo real (produto + frete) e aciona o alerta apenas quando a meta financeira do usuário é atingida.

## 🚀 Principais Funcionalidades do MVP

* **Monitoramento Ativo (Pull):** Varredura sob demanda de produtos com base no preço-alvo definido pelo usuário.
* **Cálculo de Custo Real:** A regra de negócio avalia o valor final somando o preço do produto ao valor do frete.
* **Alerta Zero Ruído:** Notificações disparadas estritamente quando a meta de preço é batida.
* **Validação de Histórico:** Proteção contra a "metade do dobro" ao consultar preços previamente registrados no banco de dados.
